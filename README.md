# Xtramile Technical Assessment Submission

This repository contains the completed solutions for the technical assessment tasks. The projects are organized into separate directories, each containing its own specific instructions, implementation details, and documentation.

GitHub Repository: [https://github.com/satriansyahw/xtramile-task](https://github.com/satriansyahw/xtramile-task)

## Repository Structure

The submission is organized into the following folders:

### 1. Task 1: ArrowDistributorApp
- **Directory**: [ArrowDistributorApp/](file:../ArrowDistributorApp/)
- **Description**: Contains the implementation for Task 1 (Arrow Distribution logic).
- **Guide**: Refer to [ArrowDistributorApp/README.md](file:../ArrowDistributorApp/README.md) inside this folder for setup, compilation, running, and specific notes.

### 2. Task 2.1: Task2_1
- **Directory**: [Task2_1/](file:../Task2_1/)
- **Description**: Contains the implementation and setup for the Task 2.1 subtask.
- **Guide**: Refer to [Task2_1/README.md](file:../Task2_1/README.md) inside this folder for detailed instructions.

### 3. Task 2.2: Task2_2 (WeatherApp)
- **Directory**: [Task2_2/](file:../Task2_2/)
- **Description**: A modern weather dashboard built with a Blazor WebAssembly frontend and an ASP.NET Core Web API backend upgraded to .NET 10. It features full client/server code sharing, robust config-driven fallback to mock weather generation, and comprehensive offline test coverage.
- **Guide**: Refer to [Task2_2/README.md](file:../Task2_2/README.md) inside this folder for complete API endpoint contracts, configuration, build, running, and test execution instructions.

## Quick Navigation Guide for Reviewers

To review and run any of the tasks:
1. Clone the repository:
   ```bash
   git clone https://github.com/satriansyahw/xtramile-task.git
   ```
2. Navigate to the desired task directory (e.g., `cd Task2_2`).
3. Follow the steps outlined in that specific folder's `README.md` to restore packages, build, run, or execute unit tests.
